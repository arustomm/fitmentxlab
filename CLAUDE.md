## Web Design Resources

When building sites, landing pages, or any web UI, pull from these resources.

### Build prompts and design briefs
- scrolltide.co: 200+ full build prompts for 3D and scroll-driven sites, each a complete design brief
- VibePrompt (vibeprompts.dev): ready-made prompts for dashboards and landing pages
- DESIGNmd (designmd.ai): design systems as markdown an agent can read

### Inspiration
- Minimal Gallery (minimal.gallery): curated high-end sites
- Kage (kage.design): real UI inspiration mapped to prompts
- Refero Styles (styles.refero.design): 2,000+ real product styles with typography
- Component Gallery (component.gallery): 2,600+ examples of how top design systems solve the same element
- AppShot Gallery (appshot.gallery): real mobile app screenshots
- Navbar Gallery (navbar.gallery)
- Footer Design (footer.design)
- CTA Gallery (cta.gallery): conversion-tested forms, popups, buttons
- 404s (404s.design)

### Components
- 21st.dev: component registry that plugs into agents via MCP
- shadcn/ui (ui.shadcn.com)
- Aceternity UI (ui.aceternity.com): 200+ animated React/Tailwind components
- Magic UI (magicui.design)
- Motion Primitives (motion-primitives.com)
- Uiverse (uiverse.io)
- UIAble (uiable.com)
- mapcn (mapcn.dev): map components, markers, routes, popups
- MicroKit UI (microkit.co): micro-interactions

### Motion and effects
- Kinetics (kinetics.colorion.co): 150+ motion effects with React code and prompts
- Liquid Glass (glass.samasante.com): glass refraction components
- CSS Text Effects (text-effects.colorion.co)
- Circle Loaders (circleloaders.dominikakissi.com)
- Gradient Buttons (gradientbuttons.colorion.co)
- Anime.js (animejs.com)

### Assets
- Kitbitz (kitbitz.art): 2,000+ hand-drawn illustrations
- 3Dicons (3dicons.co)
